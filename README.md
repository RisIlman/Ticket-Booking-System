# STARLINE CINEMA  Ticket Booking System

A command-line ticket booking program written in Python.

## Features

- Choose from 4 movies
- Pick a showtime
- Select up to 5 seats from a seat map (Premium and Basic pricing)
- Optionally add a beverage
- Booking summary with the grand total

## How to Run

1. Install Python 3
2. Download or clone this repo
3. Run in the terminal :

    python cinema.py

## Example Output 

Movie      : The Batman
Showtime   : 10:00 AM
Seats      : A1
Total Price: RM20.00
Beverage   : No beverage (RM 0.00)
Grand Total: RM20.00
